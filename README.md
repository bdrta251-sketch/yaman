# YAMAN — Promotional Catalog

This repository hosts a multilingual (Arabic, Turkish, English) storefront prototype using GitHub Pages.

## Included now
- Premium responsive storefront homepage, 8 catalog-based category tiles
- Search and sort for 13 *preliminary* product codes
- Local browser quote-request list; copy selected codes
- Browser-local PDF preview selector; a user must select their own local PDF
- Responsive design and GitHub Pages deployment

## Important limitations
- **The original 506-page PDF and all its page images are not hosted in this repository.** The PDF picker only opens the selected PDF for that browser session, without uploading it.
- No individual product photos have been verified and linked to product codes.
- No prices, payment integration, inventory or order sending.
- The site must not be marketed as a completed online store until the original catalog assets and product data are added and verified.

## Source
A user-supplied 506-page Happy Gifts 2020 product catalog (scanned image PDF).
